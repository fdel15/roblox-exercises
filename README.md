# roblox_lua_exercises
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.6.1.

## Purpose

This repo is a collection of exercises inspired by the book [The Ultimate Roblox Game Building Cookbook | Game Development](https://www.amazon.com/dp/1805121596). Working with gemini, we are recreating the recipes using lua code. The goal is to learn how to build different objects in lua to improve my skills at coding roblox games.

#### [Link to Gemini Conversation](https://gemini.google.com/app/8577d06f4a7a549d)

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "roblox_lua_exercises.rbxlx"
```

Next, open `roblox_lua_exercises.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
